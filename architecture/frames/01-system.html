Outbound calling system

Read a number. Place the call. Mark it called.

n8n holds the list. ElevenLabs holds the agent. Twilio holds the line people see.

n8n

Reads pending rows from the Call queue, asks for the dial, then writes the row as called.

ElevenLabs

Runs the agent. The voice, the script, and the guardrails stay here.

Twilio

The South African number. It is imported into ElevenLabs once, then used for every call.
